# PhotoMark v0.1.2

离线批量照片水印工具，提供 **Apple 芯片 Mac** 和 **Windows x86-64** 两个版本。

## 下载与运行

在下方 **Assets** 中选择适合自己系统的文件：

| 附件 | 用途 |
| --- | --- |
| `PhotoMark-0.1.2-mac-arm64.zip` | Apple 芯片 Mac 成品。解压后将 `PhotoMark.app` 拖入“应用程序”运行。 |
| `PhotoMark-0.1.2-windows-x64.exe` | Windows 64 位便携成品，双击运行。 |
| `使用说明.md` | 功能、操作方式、支持格式与断点恢复说明。 |
| `产物说明.md` | 成品、源码、测试目录与可清理文件的用途说明。 |
| `SHA256SUMS.txt` | 安装包和说明文档的完整性校验值。 |

普通使用无需安装 Node.js，也不需要下载源码或开发依赖。需要源码时，下载 GitHub 自动提供的 **Source code (zip)** 或 **Source code (tar.gz)**。

## 功能

- 日期来源可选 EXIF 拍摄时间、文件名时间、文件修改时间或手动指定；支持自定义年月日时分秒格式。
- 地点默认自动提取照片内嵌名称或 EXIF GPS 坐标。缺失时给出提示，并允许手动补充；手动补充只用于没有自动位置的照片。
- 水印位置支持四角，文字大小、边距、颜色、不透明度、描边与底色可调。
- 支持原图对照及原始分辨率 1:1 预览。
- 支持包含子文件夹的批量处理、暂停、重启恢复和失败重试；原照片保留。
- 主界面采用“日期、地点、样式、导出”四个设置页签，适配窗口高度，常用操作无需滚动。
- 默认 PNG 无损压缩，可选 TIFF LZW 或 JPEG 质量 100 / 4:4:4。输出不缩小原图。

## 使用前了解

- 当前应用未签名。Mac 首次打开可能需要在“系统设置 → 隐私与安全性”中选择“仍要打开”；Windows 可能提示未知发布者。
- PNG / TIFF 无损指保存水印合成后的画面；添加水印会改变覆盖区域，JPEG 再编码仍有损耗。请保留原始照片。
- 输入支持 JPG、PNG、静态 WebP、单页 8 位 TIFF；暂不直接支持 HEIC、RAW、高位深及动画或多页图像。
- 全程离线。GPS 只显示经纬度，不联网转换为城市或地址。
- Mac 成品已在 Apple 芯片设备上运行验证；Windows 桌面交互仍需真机验收。自动构建会在对应系统执行核心测试和打包。
- 输出目录的隐藏 `.photomark/` 是断点记录，需要续处理时应保留。
