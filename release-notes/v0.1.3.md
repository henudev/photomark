# PhotoMark v0.1.3

## 新增 PNG / JPG 导出格式切换

- “开始批量处理”按钮旁新增始终可见的 **导出格式** 下拉框，提供 **PNG · 无损** 和 **JPG · 高质量** 两个选项。
- “导出”页签提供 PNG / JPG 格式卡片，与下拉框同步；选择会自动保存，重启后保留。
- 默认 PNG，无损保存添加水印后的画面；JPG 使用质量 100、4:4:4，通常体积更小，但仍属于有损压缩。
- 实际输出分别为 `.png` 或 `.jpg`，均保留原始尺寸。
- 正在批量处理时锁定格式，避免同一任务混用格式；不同格式使用独立的断点记录。
- 兼容恢复旧版 TIFF 任务，正常的新任务选择只显示 PNG / JPG。
- 保持主界面无需滚动，已检查三种窗口尺寸下的布局。

## 保留功能与限制

- 支持自动读取拍摄时间与地点，地点缺失时可手动补充；支持四角水印、原图对照、1:1 预览和批量断点恢复。
- 原始照片不覆盖。添加水印会改变覆盖区域；PNG 不会恢复原 JPEG 已丢失的细节。请始终保留原图。
- 输入支持 JPG、PNG、静态 WebP、单页 8 位 TIFF；暂不直接支持 HEIC、RAW、高位深及动画或多页图像。
- 完全离线，GPS 显示经纬度，不联网转换为城市地址。
- 当前成品未签名，Mac 首次运行可能需要在“隐私与安全性”中允许打开，Windows 可能提示未知发布者。
- Windows 的核心测试与构建在原生 Windows 环境执行，桌面交互仍需真机验收。
